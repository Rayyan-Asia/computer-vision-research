# AGENTS.md

Instructions for AI coding agents (Claude Code or others) working in this repository.

## Commits and authorship

- **Do not add the AI agent as an author or co-author** of any commit. No `Co-Authored-By:` trailers, no "Generated with" lines, and no other attribution to an AI tool in commit messages.
- Commits are authored only by the repository owner (the configured git user).
- The same applies to pull request descriptions: no AI attribution lines.

## Course requirement: AI-use declaration

The MSAI6330 project brief requires the final report to declare AI tool use (tool name and version, purpose, extent of assistance, and how the output was verified). Keeping AI attribution out of git history does not replace that declaration. The owner is responsible for including it in the reports.

## Project context

- Course: MSAI6330 Computer Vision, Birzeit University. Individual project; the brief is `MSAI6330_project.pdf`.
- Paper-selection research and plans live in `RESEARCH_NOTES.md`.
- Compute is limited to an Apple M1 Pro with 16 GB RAM or a free Google Colab notebook. Prefer lightweight, inference-only approaches.
